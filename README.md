# RideGlance site

Public landing page and privacy policy for RideGlance.

This repository contains only static website assets intended for GitHub Pages. The RideGlance Android source code is maintained separately.

## GitHub Pages

After pushing this repository to GitHub, enable Pages from the `main` branch and `/ (root)` folder.

The public site will then be available at:

`https://irshadj.github.io/RideGlance-site/`

The privacy policy will be available at:

`https://irshadj.github.io/RideGlance-site/privacy.html`
